


# Python String Practice

This repository contains **10 simple and practical Python programs** created to practice the fundamental Python concepts learned up to the **Strings** topic.

The main goal was not only to write code, but also to practice **problem-solving, logical thinking, working with user input, processing strings, and combining different Python methods**.

## What I Practiced

Throughout these exercises, I practiced:

* `input()`
* `int()` and `float()`
* `lower()`
* `strip()`
* `replace()`
* `split()`
* f-strings
* String indexing
* String slicing
* Reversing strings with `[::-1]`
* Method chaining
* Combining multiple string operations
* Basic calculations and formatted output

## Programs

### 1. User ID Generator

Creates a user ID from information such as first name, last name, birth year, and city.

**Purpose:** Practice `lower()`, `strip()`, slicing, and combining string operations.

### 2. Sentence Analyzer

Receives a sentence and processes different parts of the text.

**Purpose:** Practice working with strings and using `split()`.

### 3. Gmail Generator

Creates a hypothetical Gmail address using information provided by the user.

**Purpose:** Practice `strip()`, `lower()`, slicing, and f-strings.

### 4. Product Invoice

Receives product price, quantity, and discount percentage, then calculates and displays the final price.

**Purpose:** Practice user input, type conversion, calculations, and formatted output.

### 5. Text Encryption

Replaces a word in a text, converts the result to uppercase, and reverses the text.

**Purpose:** Practice `replace()`, `upper()`, and string reversing with `[::-1]`.

### 6. Product Code Analyzer

Analyzes a structured product code such as:

`IR-ARD-95-500-XL`

and extracts information such as country, city, year, price, and size.

**Purpose:** Practice string indexing and slicing with structured data.

### 7. User Report

Processes user information stored in a single string and creates a simple formatted report.

**Purpose:** Practice `split()`, indexing, `strip()`, and f-strings.

### 8. String Processing

Processes text by combining several string methods and operations.

**Purpose:** Practice combining multiple string operations to solve a problem.

### 9. Structured Text Processing

Processes structured text and extracts different parts of the data.

**Purpose:** Improve string analysis and the ability to access specific parts of text.

### 10. String Report

Splits information from a string into different parts and displays the results as a readable report.

**Purpose:** Review and combine the string concepts learned throughout the exercises.

## Project Goal

These exercises are part of my Python learning journey.

The purpose of this project is to build a strong foundation in Python through practical exercises and gradually move toward more advanced Python programming and eventually **Data Science**.
